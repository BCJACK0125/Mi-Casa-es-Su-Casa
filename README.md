# Mi Casa es Su Casa 🏠

我家的 3D 重建，可以在瀏覽器裡用第一人稱走來走去，或用第三人稱俯瞰整間房子。

搭電梯、走樓梯都可以，不過這棟樓是**輪迴**的：不管到了哪一層，推開鐵門都還是我家。

## 怎麼玩

| 操作 | 鍵盤／滑鼠 | 手機 |
| --- | --- | --- |
| 移動 | `W` `A` `S` `D`／方向鍵 | 左下搖桿 |
| 轉頭 | 滑鼠（點畫面鎖定游標） | 右半邊拖曳 |
| 開門、按電梯、看照片 | `E` 或點擊 | `E` 按鈕或輕點 |
| 跑步／跳 | `Shift`／`Space` | 搖桿推到底／`⤒` |
| 第一／第三人稱 | `V` | 👁️ |
| 俯瞰（娃娃屋剖面） | `O` | 🏠 |
| 大地圖 | `M` | 🗺️ |
| 日／夜 | `N` | 🌙 |

- **電梯**：在電梯裡看著按鈕按 `E`，或用數字鍵（`0` = 10F、`-` = 11F、`B` = B1）。
- **樓梯**：一路往上或往下走，樓層數字會一直變，但每一層都是同一個家。11F 再往上會回到 B1。
- **回憶照片**：屋子裡散落 10 個 📷，靠近按 `E` 可以看到原本拍攝的照片，跟 3D 場景對照。
- **俯瞰模式**：在地板上雙擊，就能直接跳進那個位置開始走。

## 技術

- [three.js](https://threejs.org/) r160（ES modules，透過 jsDelivr CDN 載入），不需要任何建置步驟。
- 牆面、地磚、木地板、花崗石、書背、城市夜景等材質，都用 Canvas 程式生成。
- 八駿圖、書法、大門海報、碎花窗簾、冰箱磁鐵等，是從實拍照片裁切、做透視校正後當成貼圖。
- 靜態幾何會依材質合併成少數幾個 draw call。燈光採用「光源池」，跟著玩家分配，所以燈的數量固定。另外可以開啟 GTAO 環境光遮蔽（✨）。
- 樓梯間是同一個模組上下疊了好幾份。玩家離開中間平台、踏上「下一段」樓梯時，會被無縫平移一層樓高，所以樓梯可以無限走下去。

```
index.html      介面（標題、HUD、小地圖、電梯面板、照片檢視）
style.css
src/main.js     渲染、模式切換、互動、光源池、主迴圈
src/house.js    家裡的格局、牆、門窗與家具擺設
src/building.js 電梯梯廳、輪迴樓梯、電梯
src/furn.js     家具模型
src/kit.js      材質、牆面（含門窗開口）、碰撞、幾何合併
src/tex.js      程式生成貼圖
src/player.js   移動、碰撞、樓梯高度、樓層輪迴
src/minimap.js  小地圖
src/audio.js    WebAudio 音效（電梯叮咚、腳步聲…）
src/data.js     房間範圍、回憶照片位置
assets/         照片裁切出的貼圖與回憶照片（已移除 EXIF）
```

## 本機執行

ES modules 需要透過 HTTP 載入，所以要開一個本機伺服器：

```bash
python -m http.server 8000
# 打開 http://localhost:8000
```

## 部署到 GitHub Pages

1. 把 `index.html`、`style.css`、`src/`、`assets/`、`.nojekyll` 推到 `main` 分支。
2. 到 GitHub 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`。
3. 等一兩分鐘，就能在 `https://<帳號>.github.io/Mi-Casa-es-Su-Casa/` 打開。
